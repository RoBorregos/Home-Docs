# Tasks

Tasks of the [RoboCup@Home 2026 rulebook](https://github.com/RoboCupAtHome/RuleBook) (Open Platform League) and the status of FRIDA in each one. Since 2026 there are no Stage I and Stage II anymore: all teams run the same tasks every day, and the best teams compete in the Finals on the last day.

Each task is implemented as a state machine in [`home2/task_manager`](https://github.com/RoBorregos/home2/tree/main/task_manager).

## GPSR (General Purpose Service Robot)
The operator gives the robot three commands, generated by the official command generator and rephrased by an LLM. The robot decides whether to execute them one by one or as a single plan, and returns to the instruction point. It tests task planning, people and object recognition, navigation and manipulation.

**Current status:**
The command interpreter turns each command into a sequence of actions using an LLM. Consecutive commands can be merged into a single plan, which is confirmed with the operator and executed as a behaviour tree (`py_trees`). See [GPSR](../development/integration/Task%20Breakdown/gpsr/GPSR.md).

## HRI Challenge (HRIC)
Formerly Receptionist. Two guests arrive separately, announced by a doorbell or a knock. The robot greets each guest, learns their name and favorite drink, guides them to a free seat and introduces them to each other while looking at them. The second guest hands a bag to the robot, which then follows the host to the drop-off point.

**Current status:**
The robot detects the doorbell and knocks, opens the interaction, saves each guest's face for recognition, finds a free seat, introduces the guests, takes the bag, follows the host using person re-identification and leaves the bag. See [Receptionist](../development/integration/Task%20Breakdown/Receptionist.md).

## Pick and Place Challenge (PPC)
New in 2026, it merges Storing Groceries, Serve Breakfast and Clean the Table. The robot clears the dining table (dishes to the dishwasher, trash to the bin and the other objects to the cabinet, grouped by category), sets up breakfast (bowl, spoon, cereal and milk) and clears an extra surface. Pouring and operating the dishwasher give extra points.

**Current status:**
The robot perceives the table and announces the objects, scans the cabinet shelves to group objects by category, and runs a pick and place loop that decides the placement of each object (cabinet shelf, dishwasher or trash bin). For breakfast it picks the items, places them on the dining table and pours cereal and milk into the bowl. It asks for help to open the dishwasher. See [Storing Groceries](../development/integration/Task%20Breakdown/StoringGroceries.md), [Clean the Table](../development/integration/Task%20Breakdown/CleanTable.md) and [Serve Breakfast](../development/integration/Task%20Breakdown/ServeBreakfast.md).

## Doing Laundry
The robot moves T-shirts from the washing machine or a laundry basket to a table, and folds at least one. It tests deformable object manipulation and interaction with appliances.

**Current status:**
The robot finds and picks the laundry basket, unloads it on the laundry table, picks clothes from the basket and the washing machine, and closes the washing machine. Folding is not implemented yet.

## Restaurant
Included in rulebook 2026.2 and removed in the 2027 draft. The robot works as a waiter in a real restaurant: it detects customers calling it, takes their orders, tells them to the barman and delivers them.

**Current status:**
The robot detects customers waving or calling, approaches the table, takes the order, says it to the barman and delivers it. See [Restaurant](../development/integration/Task%20Breakdown/Restaurant.md).

## Finals
The robot has to find and solve household problems by itself, such as trash on the floor, misplaced objects, people asking for help, an open dishwasher, the laundry basket and a guest at the door.

## Tasks removed since 2025

| Task | What happened |
| --- | --- |
| Receptionist | Renamed to HRI Challenge (2026). |
| Storing Groceries, Serve Breakfast, Clean the Table | Merged into the Pick and Place Challenge (2026). |
| Carry My Luggage / Help Me Carry | Removed in 2026. Taking a bag and following a person is now part of the HRIC. |
| EGPSR | Removed in 2026. Its rules are reused in the Finals. |
| Stickler for the Rules | Replaced by Give Me a Hand in 2025. |

## RoboCup@Home 2027
The [2027 rulebook](https://github.com/RoboCupAtHome/RuleBook) is still a draft. So far it removes Restaurant and changes the restart rules (the robot restarts from the entrance inside the arena).
